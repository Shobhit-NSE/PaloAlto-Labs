# Palo-Alto Labs

Hands-on Palo Alto Networks VM-Series firewall labs focused on learning, configuring, testing, and troubleshooting PAN-OS in a virtual lab environment.
This repository documents my practical journey with Palo Alto Networks firewalls through progressively structured labs,
from basic firewall configuration to advanced security, networking, VPN, IPSec site-to-site VPN, Global Protect,
URL-Filtering, SSL-Decryption and more.

## The main objectives of this repository are to:
Build practical Palo Alto Networks firewall skills

Understand PAN-OS through hands-on configuration


Configure and test VM-Series firewalls


Practice troubleshooting real-world scenarios


Document lab configurations and results
